## 01. Overview

**Data Visualization for Big Data**는 데이터 분석 및 시각화를 통해 복잡한 데이터 속에서 의미 있는 패턴과 인사이트를 발견하는 PBL 프로젝트입니다.

본 프로젝트는 데이터 수집부터 전처리, 탐색적 데이터 분석, 시각화 및 결과 해석까지의 전 과정을 수행합니다.

## 02. Objectives

- 데이터 기반 문제 정의 및 분석 방향 수립
- 데이터 수집, 정제 및 전처리
- 탐색적 데이터 분석(EDA)을 통한 주요 패턴 파악
- 효과적인 시각화 기법을 활용한 정보 전달
- 분석 결과에 기반한 인사이트 및 결론 도출
