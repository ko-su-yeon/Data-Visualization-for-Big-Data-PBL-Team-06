# GLP-1 계열 의약품 이상사례 신고 패턴 분석

**덕성여자대학교 데이터사이언스학과 · 빅데이터시각화 PBL Team 06**

7개 의약품 성분에 대해 수집된 이상사례 신고를 분석했다. 연구의 중심 질문은 **어떤 반응이 자주 보고되며, 어떤 신고에서 중대 표식이 자주 관찰되는가**이다. 성분·기간·국가·환자 특성별로 보고 패턴을 살펴보고, 추가로 반응명 코딩 전후에 사용할 수 있는 정보에 따라 중대 신고 분류 성능이 어떻게 달라지는지 비교했다.

[연구 노트북](glp1-analysis/notebooks/GLP1_PBL_All_in_One.ipynb) · [인터랙티브 대시보드 HTML](glp1-analysis/dashboard/GLP1_Interactive_Dashboard.html) · [분석 결과표와 그림](glp1-analysis/results/)

## 데이터 구성과 전처리

| 항목 | 이번 분석에 사용한 자료 |
|---|---|
| 원본 파일 | 팀이 공유한 `adverse_events.xlsx` · 149,209행, 16열 |
| 관측 기간 | 2012년 11월 23일~2025년 1월 17일. 첫해와 마지막 해는 부분 연도 |
| 신고 단위 | 고유 신고 ID 54,170건. 이 중 중대 신고 15,502건(28.6%) |
| 반응 단위 | 신고 ID와 정규화한 반응명의 조합 149,209건. 서로 다른 반응명 4,604개 |
| 전처리 출력 | 노트북 실행 시 `clean_data/glp1_report_level.csv.gz`와 `clean_data/glp1_reaction_level.csv.gz` 생성 |
| 팀 공유 결과 파일 | `GLP1_PBL_Results.zip`. 저장소용으로 선별한 그림과 집계표는 [results](glp1-analysis/results/)에서 확인 |

하나의 신고에 오심과 구토가 함께 기록되면 전체 신고 수에는 한 번, 두 반응의 빈도에는 각각 한 번 포함된다. 중대 여부는 원본의 `serious` 필드를 사용했다. 중대 신고 7,957건에서 제공된 네 가지 중대성 세부 플래그가 모두 꺼져 있어, 플래그 합산으로 라벨을 재구성하면 원래 표식이 달라진다. 나이는 연 단위로 통일하고 체중이 0kg 이하이거나 500kg을 넘으면 주 분석에서 결측 처리했다.

### 주요 결과

**오심은 가장 자주 기록됐고, 구토를 포함한 신고에서는 중대 표식의 비율이 더 높았다.** 오심 신고 7,629건 중 1,782건(23.4%), 구토 신고 3,661건 중 1,419건(38.8%)이 중대 신고였다. 상위 15개 반응 표에는 반응별 신고 수, 중대 신고 수, 중대 비율과 Wilson 95% 신뢰구간을 함께 제시했다.

**2024년에는 같은 성분 안에서도 보고 국가별 중대 비율이 크게 달랐다.** 세마글루타이드의 영국 신고 282건 모두에 중대 표식이 있었고, 미국에서는 2,008건 중 680건에 해당 표식이 있었다. 이 비교에서 분모는 해당 조건으로 수집된 신고 건수다. [2024년 비교 집계표](glp1-analysis/results/comparison_2024.csv)

| 2024년 보고 국가 | 성분 | 전체 신고 | 중대 신고 | 중대 비율 |
|---|---|---:|---:|---:|
| 미국 | 세마글루타이드 | 2,008 | 680 | 33.9% |
| 미국 | 티르제파타이드 | 4,803 | 175 | 3.6% |
| 영국 | 세마글루타이드 | 282 | 282 | 100.0% |
| 일본 | 세마글루타이드 | 141 | 137 | 97.2% |

### 대시보드 사용법

[대시보드 HTML](glp1-analysis/dashboard/GLP1_Interactive_Dashboard.html)을 내려받아 브라우저에서 연다. 성분을 `semaglutide`, 시작·종료 연도를 모두 `2024`, 국가를 `US`로 선택하면 위 표의 첫 행을 확인할 수 있다. 성별 필터를 추가하면 해당 집단의 신고 건수, 중대 건수, 중대 비율과 상위 반응표가 함께 바뀐다. **집계표 저장 (CSV)** 버튼으로 현재 선택한 반응표를 내보낼 수 있다. 연령대별 비교는 노트북과 정적 그림에서 제공한다.

## 머신러닝 기반 중대 신고 분류

목표 변수는 각 신고에 기록된 중대 여부다. 신고 ID와 중대성 결과를 직접 드러내는 변수는 입력에서 제외했다. 2022년 7월 14일까지의 신고로 학습하고 이후 검증 기간을 후보 선택과 확률 보정·판정 임계값 결정에 나누어 사용했다. 최종 평가는 2023년 12월 30일~2025년 1월 17일의 신고 8,113건(중대 2,014건)에서 수행했다.

| 모델과 사용 정보 | 평균 정밀도(AP) | ROC-AUC | F1 | 재현율 |
|---|---:|---:|---:|---:|
| 팀 기준 모델 · 랜덤 포레스트 재현 | 0.5364 | 0.6530 | 0.4425 | 0.4866 |
| A · 성분, 국가, 환자 특성, 접수일 등 기본정보 | 0.7112 | 0.7180 | 0.6949 | 0.5665 |
| B · 기본정보와 코딩된 반응명·반응 수 | 0.9250 | 0.9531 | 0.8692 | 0.8793 |

A와 B 모두 검증에서 로지스틱 회귀가 선정됐다. 같은 시험 신고에서 B의 AP는 A보다 0.2138 높았다. 다만 A의 ROC-AUC는 미국 신고 6,829건만 평가했을 때 0.354였다. 전체 성능을 해석할 때는 시험 기간의 성분 및 국가 구성도 함께 고려해야 한다. B의 성능은 반응 코딩이 끝난 시점의 회고적 분류에 해당한다. [시험 성능 곡선](glp1-analysis/results/figures/Fig04.png)

## 재현 방법

1. `glp1-analysis/notebooks/GLP1_PBL_All_in_One.ipynb`를 Google Colab에서 열고 CPU 런타임을 선택한다.
2. **런타임 → 모두 실행**을 누르고 파일 선택 창에 팀 원본 `adverse_events.xlsx`를 올린다. 이미 업로드한 경우 첫 설정 셀의 `INPUT_PATH`에 파일 경로를 입력한다.
3. 전처리 감사표에서 고유 신고 54,170건과 중대 신고 15,502건을 확인한다. 마지막 셀까지 실행하면 정제 데이터, 결과표, 그림과 대시보드가 포함된 ZIP이 생성된다.

분석에는 Python, pandas, NumPy, SciPy, Matplotlib, scikit-learn을 사용했다. 독립형 대시보드는 HTML·CSS·JavaScript로 구현했다.
