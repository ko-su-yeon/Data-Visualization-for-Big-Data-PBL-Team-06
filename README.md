# GLP-1 계열 의약품 이상사례 신고 패턴 분석

**덕성여자대학교 데이터사이언스학과**

7개 성분의 이상사례 신고를 바탕으로 성분·연도·국가별 보고 패턴과 환자 특성·반응별 중대 신고 비율을 분석했다. 추가로 신고 기본정보에 코딩된 반응명을 더했을 때 중대 신고 분류 성능이 어떻게 달라지는지 비교했다.

<br>

## 공유 자료

| 파일명 | 내용 |
|---|---|
| `adverse_events.xlsx` | 분석에 사용한 이상사례 신고 원자료 |
| `GLP1_PBL_All_in_One.ipynb` | 전처리, 탐색적 분석, 시각화, 모델 학습·평가 코드와 실행 결과 |
| `GLP1_Interactive_Dashboard.html` | 성분·연도·국가·성별로 신고를 탐색하는 대시보드 |
| `GLP1_PBL_Results.zip` | 분석 결과 압축 파일 |

별도로 공유한 그림 두 장에는 신고 빈도 상위 15개 반응의 중대 신고 비율과 2024년 성분별·국가별 비교가 담겨 있다.

<br>

## 데이터 구성과 전처리

| 항목 | 분석 결과 |
|---|---|
| 관측 기간 | 2012년 11월 23일~2025년 1월 17일 |
| 원본 데이터 | 149,209행, 16열 |
| 고유 신고 | 54,170건 |
| 중대 신고 | 15,502건(28.6%) |
| 서로 다른 반응명 | 4,604개 |

한 신고에 오심과 구토가 함께 기록된 경우, 전체 신고 건수에서는 한 번, 반응별 집계에서는 오심과 구토에 각각 한 번 포함했다. 중대 여부는 원본의 `serious` 값을 사용했다. 나이는 연 단위로 통일했고, 체중이 0kg 이하이거나 500kg을 넘으면 주 분석에서 결측 처리했다. 연도별 추이를 비교할 때는 첫해와 마지막 해에 일부 기간만 포함된 점을 고려했다.

| 고수연 | 성분·성별·연령대별 중대 신고 비율, 주요 반응의 신고 빈도와 중대 비율 |

## 주요 분석 결과 (Key Findings)

### 신고 빈도 상위 15개 반응

오심은 7,629건으로 가장 자주 기록됐다. 이 중 1,782건(23.4%)이 중대 신고였다. 구토는 3,661건으로 오심보다 적게 보고됐지만, 구토를 포함한 신고 중 중대 신고는 1,419건(38.8%)이었다. 공유한 그림에서 각 반응의 점은 중대 신고 비율을, 가로선은 Wilson 95% 신뢰구간을 나타낸다.

### 2024년 성분별·국가별 비교

처음 두 행은 미국에서 성분별로 비교한 결과다. 첫째·셋째·넷째 행은 Semaglutide 신고를 보고 국가별로 비교한 결과다.

| 보고 국가 | 성분 | 전체 신고 | 중대 신고 | 중대 비율 |
|---|---|---:|---:|---:|
| 미국 | Semaglutide | 2,008 | 680 | 33.9% |
| 미국 | Tirzepatide | 4,803 | 175 | 3.6% |
| 영국 | Semaglutide | 282 | 282 | 100.0% |
| 일본 | Semaglutide | 141 | 137 | 97.2% |

영국의 100%는 해당 조건으로 수집된 282건 모두에 중대 표식이 있었다는 뜻이다. 이 자료에는 전체 투약자 수와 미보고 사례가 없어 국가별·성분별 이상반응 발생률이나 상대적 안전성을 추정할 수 없다.

## 인터랙티브 대시보드

1. `GLP1_Interactive_Dashboard.html`을 브라우저에서 연다.
2. 성분을 `Semaglutide`, 시작 연도와 종료 연도를 `2024`, 국가를 `US`로 선택한다. 성별은 전체로 둔다.
3. 위 표의 첫 행과 같은 **고유 신고 2,008건, 중대 신고 680건, 중대 비율 33.9%**를 확인한다.
4. 필터를 변경하면 신고 건수와 상위 반응표가 함께 바뀐다. **집계표 저장 (CSV)** 버튼으로 현재 선택한 조건의 반응표를 저장할 수 있다.

## 머신러닝 기반 중대 신고 분류

통합 노트북에서는 시간순으로 데이터를 나눠 신고에 기록된 중대 여부를 분류했다. 최종 시험 기간은 2023년 12월 30일~2025년 1월 17일이며, 신고 8,113건 중 중대 신고는 2,014건이었다.

| 모델과 사용 정보 | 평균 정밀도(AP) | ROC-AUC | F1 점수 | 재현율 |
|:---:|:---:|:---:|:---:|:---:|
| 기준 모델 · 랜덤 포레스트 재현 | 0.5364 | 0.6530 | 0.4425 | 0.4866 |
| A · 성분, 국가, 환자 특성, 접수일 등 기본정보 | 0.7112 | 0.7180 | 0.6949 | 0.5665 |
| B · 기본정보와 코딩된 반응명·반응 수 | 0.9250 | 0.9531 | 0.8692 | 0.8793 |

A와 B 모두 검증에서 로지스틱 회귀가 선정됐다. 같은 시험 신고에서 B의 AP는 A보다 0.2138 높았다. B의 성능은 반응 코딩이 끝난 신고를 회고적으로 분류한 결과다.

## 분석 재현 방법

1. Google Colab에서 `GLP1_PBL_All_in_One.ipynb`를 열고 CPU 런타임을 선택한다.
2. **런타임 → 모두 실행**을 누르고 파일 선택 창에 원본 엑셀을 올린다. 이미 업로드했다면 첫 설정 셀의 `INPUT_PATH`에 실제 파일 경로를 입력한다.
3. 전처리 결과에서 고유 신고 54,170건과 중대 신고 15,502건을 확인한 뒤, 노트북의 EDA·모델 평가 셀에서 표와 그림을 확인한다.
