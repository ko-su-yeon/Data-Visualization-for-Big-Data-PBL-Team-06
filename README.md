## 프로젝트 소개

- **연구 주제:** GLP-1 계열 의약품의 이상사례 보고 패턴 분석 및 머신러닝 기반 중대 신고 여부 예측
- **연구 목적:** 의약품별 신고 특성 및 중대 신고 패턴 파악
- **연구 방향:** 통계 분석과 탐색적 데이터 분석 중심
- **연구 방법:** 의약품·시계열·환자 특성별 분석, 인터랙티브 시각화, 머신러닝
- **최종 결과물:** 데이터 시각화 대시보드 및 학술대회 논문

### 주요 연구 영역

| 분석 영역 | 주요 내용 |
|---|---|
| 의약품별 분석 | 의약품별 전체 신고 건수 및 분포 |
| 시계열 분석 | 연도별 신고 추세 및 의약품별 변화 |
| 국가별 분석 | 국가별 이상사례 신고 현황 |
| 환자 특성 분석 | 성별·연령대별 중대 신고 비율 |
| 이상사례 분석 | 주요 이상사례 빈도 및 중대 신고 비율 |
| 머신러닝 | 중대 신고 여부 예측 및 주요 변수 분석 |

> **연구 범위**
>
> - 이상사례 신고 데이터의 통계적 특성 및 보고 패턴 분석
> - 신고 건수와 실제 부작용 발생률 구분
> - 중대 신고 비율과 실제 의약품 위험도 구분
> - 자발적 신고 데이터만으로 인과관계 판단 불가

## 데이터 구성

### 활용 데이터

| 구분 | 파일명 | 활용 목적 |
|---|---|---|
| 원본 데이터 | `adverse_events.csv` | Kaggle GLP-1 이상사례 보고 데이터 |
| 신고 단위 데이터 | `glp1_report_level.csv` | 신고 건수·중대 신고 분석 및 예측 |
| 이상사례 단위 데이터 | `glp1_reaction_level.csv` | 이상사례 유형별 빈도 및 특성 분석 |

### 데이터 전처리

- 중복 신고 ID 및 반복 기록 검토
- 결측치 및 비정상 값 확인
- 신고 날짜 유효성 검증
- 중대 신고 여부 라벨 생성 및 충돌 검토
- 신고 단위·이상사례 단위 데이터 구성
- 머신러닝 데이터 누수 가능성 검토

## 분석 내용

### 약물 및 시간에 따른 이상사례 보고 패턴

**담당: 서연**

- 약물별 전체 신고 건수 비교
- 연도별 이상사례 신고 건수 추이
- 약물별·연도별 신고 분포 히트맵
- 국가별 이상사례 보고 현황

### 환자 특성 및 이상사례 유형에 따른 중대 신고 패턴

**담당: 수연**

- 약물별 중대 신고 비율 비교
- 성별·연령대별 중대 신고 비율
- 주요 이상사례 신고 빈도 상위 15개
- 주요 이상사례별 중대 신고 비율

## 데이터 시각화

### 주요 시각화 항목

| 분석 영역 | 시각화 내용 |
|---|---|
| 약물별 신고 현황 | 약물별 전체 신고 건수 비교 |
| 연도별 추세 | 연도별 이상사례 신고 건수 변화 |
| 약물·연도별 분포 | 약물별·연도별 신고 분포 히트맵 |
| 국가별 현황 | 국가별 이상사례 신고 건수 |
| 약물별 중대 신고 | 약물별 중대 신고 비율 |
| 환자 특성 | 성별·연령대별 중대 신고 비율 |
| 주요 이상사례 | 신고 빈도 상위 15개 |
| 이상사례별 중대 신고 | 주요 이상사례별 중대 신고 비율 |

### 인터랙티브 대시보드

- 약물별 신고 현황 조회
- 연도 및 국가별 신고 패턴 탐색
- 성별·연령대별 중대 신고 비율 비교
- 주요 이상사례 유형별 분포 확인
- 조건별 필터링 및 결과 비교

**대시보드 링크:** 개발 후 추가

### 논문 수록용 시각화

- 주요 분석 결과 중심의 그래프 선정
- 2쪽 논문 분량을 고려한 그림·표 구성
- 300 DPI 이상 이미지 저장
- 그래프 색상·범례·축 표기 통일
